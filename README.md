# Outfit Tracker

衣装（コーデ）を管理・記録するWebアプリケーション。洋服のアイテムを登録し、コーディネートを作成して、日々の着用記録と香水の使用記録を管理できます。

## 機能

### 🧥 アイテムの登録
- **トップス・アウター・ボトムス**: カテゴリー、ブランド、詳細、色、サイズ、丈を登録
- **靴**: ブランド、詳細、色を登録
- **香水・その他**: カテゴリー、ブランド、詳細を登録

### 👗 コーデの登録
- 登録したアイテムを組み合わせてコーディネートを作成
- コーデに詳細説明を追加可能
- 各カテゴリから1つずつアイテムを選択

### 📝 着用記録
- コーデの着用日時を記録
- 香水の使用日時を記録

### 📊 履歴管理
- コーデの着用履歴を表示
- 香水の使用履歴を表示

## 技術スタック

- **フロントエンド**: HTML5, CSS3, Vanilla JavaScript
- **ストレージ**: IndexedDB（ローカルストレージ）
- **ブラウザ互換性**: 最新のモダンブラウザ対応

## インストール・使用方法

1. ファイルをダウンロード
```bash
git clone <repository-url>
cd OutfitTracker
```

2. ブラウザでHTMLファイルを開く
```bash
open index.html
```
または、ブラウザにドラッグ&ドロップしてください。

3. 簡易サーバーで実行（オプション）
```bash
python -m http.server 8000
# ブラウザで http://localhost:8000 にアクセス
```

## 使用方法

1. **アイテムを登録**
   - 「アイテムの登録」セクションで洋服や香水を追加

2. **コーデを作成**
   - 「コーデの登録」セクションで登録したアイテムを選択してコーディネートを作成

3. **着用記録**
   - 「コーデの記録」で着用したコーデを記録
   - 「香水の記録」で使用した香水を記録

4. **履歴確認**
   - 「コーデの履歴」「香水の履歴」でこれまでの記録を確認

## データ保存

すべてのデータはブラウザの IndexedDB に保存されます。
- ローカル環境のみで動作
- クラウド同期なし
- ブラウザのキャッシュをクリアするとデータが削除されます
